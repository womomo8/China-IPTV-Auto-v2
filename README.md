China-IPTV-Auto V3

自动发现、筛选和验证 IPTV 直播源，持续生成适用于中国大陆网络环境的 IPv4 直播订阅。

项目目标

不追求线路数量，只保留经过验证、符合发布条件的有效线路。

优先满足中国移动宽带用户的使用需求。

工作流程

1. 广泛发现：从多个来源采集直播源。
2. 数据整理：解析、去重、IPv4 准入。
3. 快速筛选：淘汰明显无效的线路。
4. 深度验证：使用 FFprobe、FFmpeg 验证媒体流。
5. 国内实测：在真实国内网络环境中验证播放能力。
6. 安全发布：只发布符合正式资格的线路。

自动运行

使用 GitHub Actions 自动执行：

- 每天北京时间 06:00 自动运行。
- 支持手动正式运行。
- 支持手动测试运行。
- 测试运行不会覆盖正式订阅。

项目原则

- 只发布符合验证要求的线路。
- 不用海外测试冒充国内实测。
- 不以采集数量代替实际可用性。
- 发布失败时保护已有正式订阅。
- 保持程序轻量，避免不必要的复杂功能。

项目仍在建设中，实际完成情况以仓库代码和测试结果为准。
