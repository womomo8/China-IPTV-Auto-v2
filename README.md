自动发现、筛选# China-IPTV-Auto-v3

自动发现、筛选和验证 IPTV IPv4 直播源，并生成 M3U 订阅。

## 订阅地址

正式订阅文件：

`output/iptv.m3u`

Raw 订阅地址：

https://raw.githubusercontent.com/womomo8/China-IPTV-Auto-v3/main/output/iptv.m3u

注意：首次成功生成并发布订阅文件后，该地址才可以正常使用。

## 自动运行

GitHub Actions 每天北京时间 06:00 自动运行一次，更新正式订阅。

## 手动运行

支持两种手动运行方式：

- 正式运行：执行完整流程，符合发布条件时更新正式订阅。
- 测试运行：执行检测流程，但不覆盖正式订阅。

## 检测说明

订阅中的线路经过项目设定的检测流程。

检测通过不代表所有地区、运营商和播放设备都能保证正常播放。实际效果还会受到网络环境和线路状态影响。

## 项目文档

- `CORE_FLOW.md`：系统总流程和技术规范。
- `MASTER_PLAN.md`：施工顺序和验收标准。
- `PROGRESS.md`：项目进度、测试证据和下一步工作。

## 输出规则

正式订阅只包含本轮验证通过的线路。

当没有合格线路、关键流程发生故障或发布校验失败时，保留上一份正式订阅。验证 IPv4 IPTV 直播源，只发布通过规定检测的线路。

项目目标

以线路质量为第一目标，不追求数量，不使用未经验证的线路凑数。

核心流程

广泛发现 → 数据整理 → 快速筛选 → 深度验证 → 安全发布

检测说明

目前以 GitHub Actions Runner 所在网络环境的检测结果作为依据。

云端检测通过不代表所有地区、运营商和用户家庭网络都能正常播放。
