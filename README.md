China-IPTV-Auto-v2

«一个统一的 IPTV 公开线路自动发现、筛选、检测、评分与发布项目。»

📘 项目说明

本仓库以自动化、一体化运行为建设目标。

项目采用一个主仓库、一条自动化主流程、一套统一数据库和一个正式订阅出口。所有业务模块最终统一由主流程调度，避免形成互相独立、需要人工协调的处理流程。

项目总方案： "docs/MASTER_PLAN.md" (docs/MASTER_PLAN.md)

整体流程说明： "docs/CORE_FLOW.md" (docs/CORE_FLOW.md)

🔄 自动化目标流程

公开来源发现
→ 线路采集与解析
→ 正式频道匹配
→ IPv4准入与无效线路过滤
→ 固定本轮候选名单
→ 基础测速
→ 质量评分
→ 深度检测
→ 内容检查
→ 稳定性复测
→ 网络出口验证
→ 发布资格审核
→ 生成并检查订阅
→ 安全更新与备份

每个阶段必须有明确的执行条件、完成条件、停止条件和数据交接规则。任务中断后，应能够在原任务基础上安全恢复。

🛡️ 数据与发布保护

- 本轮候选名单必须固定，下游不得擅自扩大候选范围。
- 历史数据库记录必须保留，不得为了测试或筛选而清空。
- 不合格线路不得进入正式订阅。
- 发布前必须检查订阅内容和格式。
- 新版本发布失败时，必须保留上一版有效订阅。
- 未经实际测试，不得宣称功能已经完成。

⚙️ 当前项目状态

本项目仍处于一体化整改和集成阶段。

- 正式频道目录以38个频道为准。
- 主流程、候选范围、阶段调度、任务恢复及发布功能仍需按总方案逐项核对和验收。
- 正式订阅地址尚未确认可用。
- 定时自动任务保持暂停，未经整体验收和用户明确确认，不得恢复。

🎯 最终目标

建设一个能够自动发现公开线路、统一筛选检测、持续记录数据、安全发布和自动恢复任务的完整 IPTV 自动化系统。

一个主仓库、一条自动化主流程、一个主程序入口、一套统一数据库、一份正式频道目录、一份统一配置、一套质量标准、一个正式发布出口。
