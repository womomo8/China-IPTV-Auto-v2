🏗️ 一体化架构

本项目坚持：

1. 一个主仓库。
2. 一条自动化主流程。
3. 一个主程序入口。
4. 一套统一数据库。
5. 一份38个正式频道目录。
6. 一份统一运行配置。
7. 一套统一检测和评分标准。
8. 一个正式订阅发布出口。

所有功能最终统一接入 "iptv_auto/pipeline.py"，不得形成互相独立的业务流程。

🛡️ 发布保护

- 检测不合格的线路不得进入正式订阅。
- 发布前必须检查订阅文件。
- 新版本发布失败时保留上一版有效订阅。
- 正式订阅采用安全更新方式。
- 不得将未经验证的线路标记为可用。
